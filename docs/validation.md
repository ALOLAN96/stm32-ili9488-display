# 验证记录

当前范围为独立组件及接入模板。目标为STM32F407、FSMC 16位8080和ILI9488。

- Device、port和轻量Graphics共50个主机用例，O0/O2累计100次通过。
- 真实LVGL v9.2.2主机运行5个用例通过，覆盖生命周期、数字变短重绘、故障恢复、超时和横屏。
- 实际LVGL及显示适配共315个编译单元通过Cortex-M4对象编译。
- LVGL固定到7f07a129e8d77f4984fff8e623fd5be18ff42e74。

验证环境为Windows x64、Clang16。详细执行命令见README及tests脚本。完整STM32固件链接、实板初始化、色彩、撕裂、时延、内存与栈余量仍待验证。
